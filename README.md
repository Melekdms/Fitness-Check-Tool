# Fitness-Check-Tool

Ein Python-Programm, das anhand von Alter, Gewicht, Größe, Trainingsstunden und Ziel ein Fitness-Level berechnet, den BMI ausgibt und einen Trainingsplan vorschlägt.

Verwendete Skills:
- Entscheidungslogik
- Funktionen, Schleifen, Listen
- Input/Output
- Algorithmisches Denken
